# 0034: Status segment highlight stays a CSS background, no shared layoutId indicator

Date: 2026-11-22. Feature: F095.

## Context
Design M9 said the selected status segment's indicator moves with `layoutId` and `spring`. Built as a shared `motion.span`, it changed the rendering of the book page enough that the locked F091 and F009 book-page screenshot baselines failed. Those baselines belong to passing features and may not be regenerated by F095.

## Decision
The selected status segment keeps its CSS `aria-checked:bg-background` highlight, with no `layoutId` indicator. The segments and rating stars keep `whileTap={{ scale: 0.97 }}` with `quick`.

## Consequences
Changing status swaps the highlight instantly instead of sliding it. The F091 and F009 baselines stay as they are. A sliding indicator can come back in a later feature that owns those baselines.

## Data model
Every M1–M6 table stays. All new tables: RLS enabled; policies `to authenticated` on `(select auth.uid()) = user_id`; `revoke all ... from anon, authenticated` then column grants; owner via `user_id uuid not null default auth.uid()`.

`public.tags`:
| column | type | rules |
|---|---|---|
| `id` | `uuid` | `primary key default gen_random_uuid()` |
| `user_id` | `uuid` | `not null default auth.uid() references auth.users (id) on delete cascade` |
| `name` | `text` | `not null check (char_length(name) between 1 and 24)` |
| `created_at` | `timestamptz` | `not null default now()` |
- `unique index tags_user_id_lower_name_key on (user_id, lower(name))` (one "classic" per user, any case); `unique (id, user_id)` for the composite key.
- Policies select, insert, update, delete own. Grants: `select, insert (name), update (name), delete`.

`public.book_tags` (as `book_shelves`):
| column | type | rules |
|---|---|---|
| `book_id` | `uuid` | `not null` |
| `tag_id` | `uuid` | `not null` |
| `user_id` | `uuid` | `not null default auth.uid()` |
| `created_at` | `timestamptz` | `not null default now()` |
- `primary key (book_id, tag_id)`; `foreign key (book_id, user_id) references public.books (id, user_id) on delete cascade`; `foreign key (tag_id, user_id) references public.tags (id, user_id) on delete cascade`; `index book_tags_tag_id_idx on (tag_id)`.
- Policies select, insert, delete own (no update). Grants: `select, insert (book_id, tag_id), delete`.
- A tag is shown only while a book has it: `removeTag` deletes the tag when no `book_tags` row is left, and `listTags` (for `/tags` and the Tag select) keeps only tags with a count above 0, so a tag left unused by deleting its last book is hidden too. No trigger: `scripts/migration-lint.py` treats any `delete from` in a migration as destructive.
- At most 10 tags per book is an app rule (F065).

`public.up_next`:
| column | type | rules |
|---|---|---|
| `book_id` | `uuid` | `primary key` (a book is queued once) |
| `user_id` | `uuid` | `not null default auth.uid()` |
| `position` | `integer` | `not null` |
| `created_at` | `timestamptz` | `not null default now()` |
- `foreign key (book_id, user_id) references public.books (id, user_id) on delete cascade`; `index up_next_user_id_position_idx on (user_id, position)`. No unique on position (swaps stay simple); order is `position, created_at, book_id`.
- Policies select, insert, update, delete own. Grants: `select, insert (book_id), update (position), delete`.
- Trigger `up_next_before_insert`, `before insert`, `security invoker`, `set search_path = ''`: raises `check_violation` (`23514`) unless `public.books` has `id = new.book_id and status = 'want_to_read'` (visible under the caller's RLS); sets `new.position = coalesce((select max(position) from public.up_next where user_id = new.user_id), 0) + 1` (end of the queue).
- Leaving Want to read leaves the queue in the app: `updateBookStatus` (the only writer that moves a book out of Want to read) deletes its `up_next` row after a status other than `want_to_read`. As a backstop, `listUpNext` keeps only books whose status is `want_to_read`.
- Function `public.move_up_next(p_book_id uuid, p_up boolean) returns boolean`, `plpgsql`, `security invoker`, `set search_path = ''`: lock the caller's row (`for update`; not found → `false`); find the neighbour among queued Want to read books (`p_up`: the greatest `(position, created_at, book_id)` below it, else the least above it; none → `false`); swap the two positions (equal positions: move the neighbour one step past it); `true`. `revoke execute ... from public, anon; grant execute ... to authenticated`.

`public.profiles`:
| column | type | rules |
|---|---|---|
| `user_id` | `uuid` | `primary key default auth.uid() references auth.users (id) on delete cascade` |
| `display_name` | `text` | `not null check (char_length(display_name) between 1 and 40)` |
- Policies select, insert, update own (no delete; the account delete cascades). Grants: `select, insert (display_name), update (display_name)`. No row = no display name.

Function `public.import_books(p_rows jsonb) returns integer`, `plpgsql`, `security invoker`, `set search_path = ''`: for each element `{title, author, status, rating, total_pages, started_on, finished_on}` (already validated by the app): `insert into public.books (title, author, status, rating, total_pages, current_page)` with `current_page = case when total_pages is null then null when status = 'finished' then total_pages else 0 end`, `returning id`; then, when the row has dates, `update public.books set started_on = coalesce(<row>, started_on), finished_on = coalesce(<row>, finished_on) where id = <id>` (the insert triggers set today's dates; the update keeps the file's, and the M2/M6 checks still apply). Returns the number inserted. One transaction: a failing row adds nothing. Execute granted to `authenticated` only.

Function `public.delete_account() returns void` (F074's migration, not the scaffold; it needs `-- destructive-approved: docs/decisions/0017-account-delete-function.md`, which a human must accept first, so F074 is `needs_human` until then), `plpgsql`, **`security definer`**, `set search_path = ''`: `delete from auth.users where id = auth.uid();` (no-op when `auth.uid()` is null). The only security definer function: it touches only the caller's own `auth.users` row, and every user table cascades from it (`books` → `notes`, `quotes`, `reads`, `book_shelves`, `book_tags`, `up_next`; `shelves`, `reading_goals`, `tags`, `profiles`). `revoke execute ... from public, anon; grant execute ... to authenticated`.

## Contract
Types live in `lib/` on top of `lib/database.types.ts`. Actions follow M1–M6: bound ids checked with `isUuid`, `requireUser()` first, queries throw, actions turn a throw into `formError: "Could not save. Try again."`; foreign, missing and malformed ids all read as "missing".

`lib/tags.ts` (new; pure parts unit-tested, queries with stub-client tests):
- `type Tag = { id: string; name: string }`; `type TagWithCount = Tag & { count: number }`.
- `TAG_MAX = 24`, `TAGS_PER_BOOK = 10`. `type TagFormState = FormState<"name"> & { saved?: true }`.
- `parseTagName(formData): Parsed<string, "name">`: field `name`, trimmed; empty → "Enter a tag"; over 24 → "Tags are at most 24 characters".
- `sortTags(tags)`: A to Z by `localeCompare(..., "en", { sensitivity: "base" })`.
- `listBookTags(supabase, bookId): Promise<Tag[]>`, sorted.
- `listTagsForBooks(supabase): Promise<Map<string, string[]>>`: one query `book_tags.select("book_id, tag:tags(name)")`; names sorted per book.
- `addTag(supabase, bookId, name): Promise<"added" | "duplicate" | "full">`: reads the book's tags; same name ignoring case → `"duplicate"`; 10 already → `"full"`; finds my tag with `ilike` on the exact name (escaped `%`/`_`) or inserts one (a `23505` race re-reads it); inserts `book_tags` (`23505` → `"duplicate"`).
- `removeTag(supabase, bookId, tagId): Promise<boolean>`.
- `listTags(supabase): Promise<TagWithCount[]>`: `tags.select("id, name, book_tags(count)")`, sorted.
- `renameTag(supabase, id, name): Promise<"renamed" | "taken" | "missing">` (`23505` → `"taken"`).
- Actions: `addBookTag(bookId, prev, formData): Promise<TagFormState>` and `removeBookTag(bookId, tagId, formData): Promise<void>` (both ids bound with `.bind`) in `app/books/[id]/actions.ts`; `renameTagAction(tagId, prev, formData): Promise<TagFormState>` in `app/tags/actions.ts`. Each runs `isUuid` on its bound ids (bad → `formError: "Book not found"` / "Tag not found", or nothing for `removeBookTag`). `addBookTag`: `parseTagName` errors on `name`; `"duplicate"` → `name: "This book already has that tag"`; `"full"` → `name: "A book has at most 10 tags"`; a missing book (FK `23503`) → `formError: "Book not found"`. `renameTagAction`: `"taken"` → `name: "You already have that tag"`; `"missing"` → `formError: "Tag not found"`. All three revalidate `/books`, `/tags`, and `addBookTag`/`removeBookTag` also `/books/${bookId}`.
- `parseTagFilter(value, tags: Tag[]): string | undefined`: the tag name when it matches one of my tags (ignoring case), else `undefined`.
- `listTaggedBookIds(supabase, tagName): Promise<Set<string>>`.

`lib/books.ts` (changed): `booksHref` gains `tag` (order status, q, sort, shelf, tag); every existing caller keeps its output.

`lib/csv.ts` (new, pure, unit-tested):
- `CSV_COLUMNS = ["title", "author", "status", "rating", "total_pages", "started_on", "finished_on"] as const`.
- `toCsv(rows: string[][]): string`: RFC 4180: a field with `,`, `"`, CR or LF is quoted, `"` doubled; lines end `\r\n`.
- `parseCsv(text): string[][]`: the inverse; strips a leading BOM; accepts `\n` or `\r\n`; ignores a final empty line.
- Status values in the file are the stored ones: `want_to_read`, `reading`, `finished`. Empty value = empty cell. Dates `YYYY-MM-DD`.

`lib/library.ts` (new): `listExportRows(supabase): Promise<string[][]>`: my books ordered `created_at, id`, read in pages of 1,000 with `.range()` until a page comes back short (PostgREST `max_rows` is 1,000), mapped to `CSV_COLUMNS` (null → `""`), header row first.

Route handler `app/api/export/route.ts`: `GET`; `requireUser()`; `200`, `Content-Type: text/csv; charset=utf-8`, `Content-Disposition: attachment; filename="bookshelf.csv"`, body `toCsv(await listExportRows(supabase))`. RLS keeps other accounts' books out. "Download CSV" on `/library` is a plain `<a href="/api/export" download>` styled as a Button.

`lib/import.ts` (new, pure parts unit-tested):
- `IMPORT_MAX_BYTES = 1_000_000`, `IMPORT_MAX_ROWS = 1000`.
- `type ImportRow = { title: string; author: string; status: BookStatus; rating: number | null; total_pages: number | null; started_on: string | null; finished_on: string | null }`; `type SkippedRow = { line: number; reason: string }` (`line` = the row's number counting the header as 1).
- `listAllBookKeys(supabase): Promise<{ title: string; author: string }[]>`: every book of mine, in pages of 1,000 with `.range()` like `listExportRows`; the duplicate check reads this, not `listBooks`.
- `parseImport(text, existing: { title: string; author: string }[], today: string): { rows: ImportRow[]; skipped: SkippedRow[] } | { error: string }`: header must equal `CSV_COLUMNS` (else `error: "This is not a Bookshelf CSV file"`); more than 1,000 data rows → `error: "The file is too large"`. Per row, the first reason that applies skips it: empty title → "No title"; empty author → "No author"; title over 200 or author over 120 → "Title or author too long"; status not one of the three → "Unknown status"; rating not empty and not an integer 1 to 5 → "Rating must be 1 to 5"; same title and author (trimmed, ignoring case) as a book I have or an earlier row of the file → "Already on your shelf". Lenient fields: `total_pages` not an integer 1 to 10,000 → `null`; a date that is not a valid `YYYY-MM-DD` → `null`; `finished_on` kept only when finished, `started_on` only when not Want to read, `started_on` dropped when after `finished_on ?? today` (`today` = UTC date, a parameter of `parseImport` as in M6's `parseReadingDates`, since the insert trigger sets a finished book's missing `finished_on` to today); `rating` kept only when finished.
- `importBooks(supabase, rows): Promise<number>`: `rpc("import_books", { p_rows: rows })`.
- `type ImportState = { error?: string; csv?: string; rows?: ImportRow[]; skipped?: SkippedRow[]; added?: number; skippedCount?: number }`.

Server actions in `app/library/actions.ts` (new):
- `previewImport(prev, formData): Promise<ImportState>`: field `file` (`File`); missing/empty → `error: "Choose a CSV file"`; `size > IMPORT_MAX_BYTES` → `error: "The file is too large"`; `parseImport(await file.text(), await listAllBookKeys(supabase), today)`; returns `{ csv, rows, skipped }` (the preview).
- `confirmImport(prev, formData): Promise<ImportState>`: field `csv` (hidden, from the preview state); over the byte limit → "The file is too large"; re-runs `parseImport` against the current books (never trusts the client's rows); `importBooks` (a throw → `error: "Could not save. Try again."`, nothing added); returns `{ added, skippedCount }`; revalidates `/books`, `/stats`. "Cancel" resets the client state; nothing is sent.
- `next.config.ts` sets `experimental.serverActions.bodySizeLimit: "2mb"` (F069), so a 1 MB file or its text fits.

`lib/queue.ts` (new; queries with stub-client tests):
- `type QueuedBook = { bookId: string; title: string; author: string; position: number }`.
- `listUpNext(supabase)`: `up_next.select("book_id, position, book:books!inner(title, author, status)")` with `book.status = want_to_read`, ordered `position, created_at, book_id`.
- `isQueued(supabase, bookId): Promise<boolean>`.
- `queueBook(supabase, bookId): Promise<boolean>`: insert `{ book_id }`; `23505` (already queued) or `23514` (not Want to read) → `false`.
- `unqueueBook(supabase, bookId): Promise<boolean>`; `moveQueued(supabase, bookId, up: boolean): Promise<boolean>` (`rpc("move_up_next")`).
- Actions: `addToUpNext(bookId, formData)` in `app/books/[id]/actions.ts` (revalidates `/books/${bookId}`, `/up-next`); `moveUp(bookId, formData)`, `moveDown(bookId, formData)`, `removeFromUpNext(bookId, formData)` and `startFirst(bookId, formData)` in `app/up-next/actions.ts` (revalidate `/up-next`, and for `startFirst` `/books`, `/books/${bookId}`, `/stats`). `startFirst` calls `updateBookStatus(supabase, bookId, "reading")` from `lib/books.ts`; the M6 trigger sets `started_on` to today. `updateBookStatus` (changed, F071): after a successful update to a status other than `want_to_read`, `up_next.delete().eq("book_id", id)`; so the status form on the book page and Start reading both leave the queue. (Read again starts from Finished, never queued; import only inserts.)

`lib/profile.ts` (new):
- `type NameFormState = FormState<"display_name"> & { saved?: true }`.
- `parseDisplayName(formData): Parsed<string, "display_name">`: trimmed; empty → "Enter a name"; over 40 → "Names are at most 40 characters".
- `getDisplayName(supabase): Promise<string | null>`; `saveDisplayName(supabase, name)`: `upsert({ display_name: name }, { onConflict: "user_id" })`.
- `deleteAccount(supabase): Promise<void>`: `rpc("delete_account")`, then `supabase.auth.signOut()`.

## NFR
- Load: unchanged (tens of users, a few hundred books each); at most 10 tags per book, a queue of tens. `/books` adds two indexed queries (tags for the list, tag ids when filtering) to its `Promise.all`. `/tags` is one query with an embedded count. Import: at most 1 MB / 1,000 rows, parsed in memory on the server, one `rpc` in one transaction; export and the import's duplicate check read every book in pages of 1,000 (PostgREST `max_rows`), so a library past 1,000 books, which two imports can make, is never cut off.
- Security: threats are reading or changing another user's tags, queue, profile or books through ids, a forged `tag_id`/`book_id` pairing, a forged import payload, a CSV that injects formulas or breaks parsing, and deleting someone else's account. Owner RLS and column grants on every new table; composite foreign keys make cross-owner `book_tags` and `up_next` rows impossible; `move_up_next`, `import_books` and the insert trigger are `security invoker`, so the caller's RLS applies; `confirmImport` re-parses the text server side; `delete_account` is `security definer` but deletes only `auth.uid()`'s row and `anon` cannot run it. The 1 MB limit is checked before parsing and the server-action body limit caps uploads at 2 MB. CSV formula injection (a cell starting `=`, `+`, `-`, `@`) is accepted as a known limit: the file is the user's own data, opened by them.
- Cost: unchanged: local Docker, free-tier Supabase branch and Vercel preview.

## Decisions
- **The tag, queue and profile migrations in the scaffold**: those features run in parallel, and each migration regenerates `lib/database.types.ts`; building them once avoids merge conflicts. Rejected: each feature adds its own. `delete_account` stays with F074 (after F073, so no parallel conflict) because it needs a human's approval (decision 0017).
- **A tag is shown only while a book has it** (`removeTag` cleans up, lists hide count 0), so `/tags` never lists "0 books". Rejected: an after-delete trigger (a `delete from` in a migration needs a human's approval); showing unused tags (needs a delete-tag feature the backlog does not have).
- **Tag names unique per user ignoring case**, stored as first typed; filter `?tag=` matches ignoring case.
- **Queue positions with a swap function, no unique constraint**: move is one transaction; a gap after Remove is harmless. Rejected: a deferrable unique (more schema for no user-visible gain); two updates from the action (not atomic).
- **Leaving Want to read leaves the queue in `updateBookStatus`**, the one function that moves a book out of Want to read, and `listUpNext` hides any row left behind. Rejected: a trigger on `books` (its `delete from` needs a human's approval under the migration lint); deleting in each action.
- **Import confirms by re-sending the CSV text**, re-parsed on the server. Rejected: re-sending the client's parsed rows (would trust them), or re-uploading the file (React resets the form after the preview action).
- **Imported dates through `import_books`**: insert then update the dates in one transaction, so the M2/M6 insert triggers stay unchanged. Rejected: changing those triggers to keep a given date (would change Add book).
- **Status in the CSV as stored values** (`want_to_read`, `reading`, `finished`), so export and import round-trip exactly.
- **Skip reasons beyond the spec's four**: "No title", "No author", "Title or author too long", "Unknown status", "Rating must be 1 to 5", "Already on your shelf"; other bad fields import as empty.
- **Account delete via a `security definer` function** on `auth.users` with cascades, so the app needs no service-role key. Rejected: the admin API with the service-role key in the app server (a far stronger secret to hold).

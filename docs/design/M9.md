# Design M9: the redesign on the UI guide: light and dark, adaptive navigation, a library-like shelf

Builds on `docs/design/M1.md` to `M8.md`: everything there (clients, `requireUser()`, form shapes, bound actions, `isUuid`, blocking render, `ConfirmDeleteButton`, RLS, covers, sharing, paging, the live list) stays. M9 changes how the app looks and moves, not what it stores. Scope and the choices that change earlier ones: `docs/decisions/0024-m9-redesign.md`.

## Features
- F088 Light and dark: dark tokens in `app/globals.css`, `@import "./ui-base.css"` there (type styles, touch targets, `color-scheme`), Inter as `--font-sans`, every `text-sm`/`text-2xl`-style class in `app/` and `components/` replaced by a named style, `/styleguide` gains the type scale, `docs/design-system.md` rewritten (below), `app/error.tsx` added and `not-found.tsx` files restyled, every visual baseline regenerated in light and dark.
- F089 Navigation: `components/app-shell.tsx`, `components/app-nav.tsx`, `components/account-menu.tsx` replace `components/site-header.tsx`; `app/layout.tsx` renders the shell; every page's outer `<main>` becomes a plain `div` (UI, Content); `signOut(page)` helper in `e2e/accounts.ts`.
- F090 My books: `app/books/page.tsx` wraps the list part in `<Suspense>` with `components/book-list-skeleton.tsx` as fallback; `BookList` renders one list that is rows on a phone and a cover grid from `lg`; `StatusTabs` becomes a segmented control; search placeholder "Search books"; `BookCover` size `"fill"`; empty state with "Add book".
- F091 Book page: cover first; `BookStatusForm` becomes a segmented control that saves on pick; progress as `Progress` with "<read> of <total> pages"; sections rating, review, notes, quotes; Delete last.
- F092 Add sheet: `/books?add=1` opens `AddBookSheet` over the list; lookup returns up to 5 matches with covers (`lib/lookup.ts` contract change); `/books/new` unchanged as a page.
- F093 Lists: `listShelfSummaries` in `lib/shelves.ts`; rows on `/shelves`, `/tags`, `/quotes`, `/up-next`; large titles; empty states.
- F094 Stats: tiles, accent bars, `GoalRing`; two tiles per row on a phone.
- F095 Motion: the `motion` package; `MotionConfig reducedMotion="user"` inside each animating component (`BookList`, the status segments, the rating), not in `app/layout.tsx`, so pages without motion (`/styleguide`, sign-in) do not load it and stay in the LCP budget (decision 0033); list insert/remove animation in `BookList`; press and settle on the status segments and the rating.
- F096 Other pages: auth card, grouped settings rows, `/library` and `/s/[token]` on the new type and tokens.

## Contract
Server actions, route handlers and their types are unchanged except the following. Types live in the `lib/` module named.

- `createBook` (F092; replaces M1's always-redirect for the sheet, decision 0031): with `sheet=1` in the form data it returns `{ saved: true }` after `revalidatePath("/books")`; without it (`/books/new`) it redirects to `/books` as before. Errors are unchanged. `BookFormState` in `lib/books.ts` gains `saved?: true`.

Lookup (F092; changes M8's lookup contract, decision 0024):
- `type LookupBook = { title: string; author: string; totalPages: number | null; coverUrl: string | null }`; `type LookupResult = { status: "found"; books: LookupBook[] } | { status: "not_found" } | { status: "timeout" } | { status: "unavailable" }`. `found` always has 1 to 5 books.
- ISBN: as M8, one book, `coverUrl = https://covers.openlibrary.org/b/isbn/<isbn>-M.jpg?default=false` (404 when Open Library has none; the `img` then falls back to the placeholder through `onError`). Title: `search.json?title=<t>&limit=5&fields=title,author_name,number_of_pages_median,cover_i`, `coverUrl = https://covers.openlibrary.org/b/id/<cover_i>-M.jpg` when `cover_i` is a positive integer, else null. Timeout, cache (24 h, `found` and `not_found` only), `GET /api/lookup` status codes and messages are unchanged. Unit tests in `lib/lookup.test.ts` gain the five-result and cover cases.
- `e2e/fixtures/lookup.json` moves to the new shape: every `found` entry is `{ "status": "found", "books": [...] }` with `coverUrl: null` (tests never load an outside image; the placeholder shows), and the title entry has at least two matches.
- A picked match fills title, author and total pages. Its cover is shown in the match list only and is not saved to the book (covers stay uploads, M8).

Shelves (F093):
- `type ShelfSummary = Shelf & { count: number; coverPaths: string[] }`; `listShelfSummaries(supabase): Promise<ShelfSummary[]>` in `lib/shelves.ts`: one query `shelves.select("id, name, book_shelves(created_at, books(cover_path))")` (RLS limits it to the owner), ordered by name as `listShelves`; `count` = the shelf's books, `coverPaths` = up to 3 non-null `cover_path` of the most recently added books, sorted by `book_shelves.created_at` descending in JS (the nested rows are few). `/shelves` signs all of them in one `signCovers` call. Unit-tested with a fake client.

Components whose props change:
- `ConfirmDeleteButton({ heading, description, size?, triggerLabel? = "Delete", triggerVariant? = "outline" | "destructive", action, open?, onOpenChange? })` (F091): `DeleteBookButton` passes `triggerLabel="Delete book"`, `triggerVariant="destructive"` and heading `Delete <title>?`; every other caller (notes, quotes, past reads, shelves) is unchanged. This replaces decision 0008's "the book dialog's text and look are unchanged" for the book page only (decision 0032) (the dialog still names the book in its text).
- `BookCover({ title, url, size: "sm" | "lg" | "fill" })`: `fill` is the `sm` box under 1024 px (list rows) and `w-full aspect-2/3` from `lg` (the grid cell decides the width); its placeholder is a `bg-muted` cover-ratio block with a hairline and one serif initial centered (`font-heading`, `text-headline` under `lg`, `text-large-title` from `lg`), the same at every width, with no title or author on it (they show once, under the cover; decision 0029-f090-placeholder-cover-initial), still `aria-hidden` (the text under it is the accessible name). `sm` and `lg` unchanged.
- `BookStatusForm({ status, action })`: a `RadioGroup` drawn as segments (`role="radiogroup"`, label "Status", one `radio` per status named by `STATUS_LABELS`); picking one submits the form at once (`form.requestSubmit()`), the segments are disabled while pending, and "Saved"/errors show under it as today. The "Save status" button goes. `saveStatus(page, name)` in `e2e/books.ts` clicks the radio, and F091 moves the specs that set status inline to that helper (how they set status changes, not what they assert).
- `StatusTabs`: unchanged links and names ("All (n)", "Reading (n)", ...) with `aria-current="page"`, drawn as one segmented control.
- `GoalRing({ finished, goal })` in `components/goal-ring.tsx`: an SVG ring in `stroke-chart-1` on a `stroke-muted` track, with "<finished> of <goal> books" as text (not color alone).

Tokens (F088), OKLCH, brand hue about 150 (green) on warm neutrals (hue 55–85, chroma 0.005–0.02):
- Light: today's values. `chart-1` becomes the primary green (the month bars and the goal ring, so graphics do not use the interaction token `primary`), at least 3:1 on `card`.

## Decisions
- **Light and dark follow the system** with no setting, overriding the spec's "light theme only" (decision 0024). Rejected: a theme switch (not asked; the guide says follow the system).
- **One navigation component rendered for two widths** (`hidden lg:flex` / `lg:hidden`), so link names, roles and existing specs stay. Rejected: a collapsible sidebar on tablets (the tab bar is enough for 8 destinations with More).
- **The add sheet is a search param on `/books`** (`?add=1`), and the sheet closes on `saved` with `router.replace` (decision 0031): a redirect from the sheet added a history entry, and a late close could rewrite a URL the user had already left. Rejected: intercepting and parallel routes (`@modal/(.)new`), more files and slot state for the same result.
- **Status saves on pick** (segmented control), dropping "Save status"; specs set status through `saveStatus`. Rejected: segments plus a Save button (a segmented control that does nothing until a second click).
- **Sort stays a `Select`** (a popup menu with a label). Rejected: a `DropdownMenu` with radio items (same look, breaks every spec that picks a sort).
- **Lookup returns up to five matches with covers; covers are not saved** (decision 0024). Rejected: saving the Open Library cover into the bucket (a server-side fetch of outside files and a new failure mode, not asked).
- **The `/books` skeleton is a `<Suspense>` inside the page**, not `app/books/loading.tsx`, which would wrap `/books/[id]` and `/books/new` (streaming 200 before `notFound()`). Rejected: a `(list)` route group (moves the page outside F090's files).
- **No shared scaffold**: the dependency chain already serializes the shared pieces.
